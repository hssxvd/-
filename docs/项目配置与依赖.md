### 2.5 依赖冲突规避

| 问题 | 规避 |
|---|---|
| Spring Boot 2.7 与 MyBatis-Plus 3.5 兼容 | 锁定 3.5.5，不要用 3.5.6+（需要 Spring Boot 3） |
| jjwt 0.10+ 包名变了 | 用 0.11.5，API 稳定 |
| Druid 1.2.17+ 与 Spring Boot 2.7 兼容 | 锁定 1.2.20 |
| 禁止引入 spring-boot-starter-data-jpa | 约束文档 1.1，混入 JPA 会导致双数据源冲突 |
| 禁止引入 Redisson | Redis 只用 spring-boot-starter-data-redis，简单场景不需要分布式锁框架 |

### 4.1 MyMetaObjectHandler（自动填充 create_time / update_time）

```java
package com.project.groupbuy.config;

import com.baomidou.mybatisplus.core.handlers.MetaObjectHandler;
import org.apache.ibatis.reflection.MetaObject;
import org.springframework.stereotype.Component;

import java.time.LocalDateTime;

@Component
public class MyMetaObjectHandler implements MetaObjectHandler {

    @Override
    public void insertFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());
        this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }

    @Override
    public void updateFill(MetaObject metaObject) {
        this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
    }
}
```

### 5.1 统一响应体

```java
package com.project.groupbuy.common.result;

import lombok.Data;

import java.io.Serializable;

@Data
public class R<T> implements Serializable {
    private Integer code;
    private String message;
    private T data;
    private String traceId;

    public static <T> R<T> ok(T data) {
        R<T> r = new R<>();
        r.setCode(0);
        r.setMessage("success");
        r.setData(data);
        return r;
    }

    public static <T> R<T> ok() {
        return ok(null);
    }

    public static <T> R<T> fail(ErrorCode errorCode) {
        R<T> r = new R<>();
        r.setCode(errorCode.getCode());
        r.setMessage(errorCode.getMessage());
        return r;
    }

    public static <T> R<T> fail(Integer code, String message) {
        R<T> r = new R<>();
        r.setCode(code);
        r.setMessage(message);
        return r;
    }
}
```

### 5.3 全局异常处理器

```java
package com.project.groupbuy.common.exception;

import com.project.groupbuy.common.result.ErrorCode;
import com.project.groupbuy.common.result.R;
import lombok.extern.slf4j.Slf4j;
import org.slf4j.MDC;
import org.springframework.validation.BindException;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.stream.Collectors;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    // 业务异常
    @ExceptionHandler(BusinessException.class)
    public R<?> handleBusinessException(BusinessException e) {
        log.warn("[业务异常] code={}, msg={}", e.getCode(), e.getMessage());
        R<?> r = R.fail(e.getCode(), e.getMessage());
        r.setTraceId(MDC.get("traceId"));
        return r;
    }

    // 参数校验异常
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public R<?> handleValidException(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining("; "));
        log.warn("[参数校验] {}", msg);
        R<?> r = R.fail(ErrorCode.PARAM_ERROR.getCode(), msg);
        r.setTraceId(MDC.get("traceId"));
        return r;
    }

    // 权限异常
    @ExceptionHandler(org.springframework.security.access.AccessDeniedException.class)
    public R<?> handleAccessDenied(org.springframework.security.access.AccessDeniedException e) {
        log.warn("[权限异常] {}", e.getMessage());
        R<?> r = R.fail(ErrorCode.FORBIDDEN);
        r.setTraceId(MDC.get("traceId"));
        return r;
    }

    // 系统异常
    @ExceptionHandler(Exception.class)
    public R<?> handleException(Exception e) {
        log.error("[系统异常]", e);
        R<?> r = R.fail(ErrorCode.SYSTEM_ERROR.getCode(), "系统异常");
        r.setTraceId(MDC.get("traceId"));
        return r;
    }
}
```

## 六、JWT 认证配置

### 6.1 JwtUtil

```java
package com.project.groupbuy.security;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.SignatureAlgorithm;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@Component
public class JwtUtil {

    @Value("${business.jwt.secret}")
    private String secret;

    @Value("${business.jwt.expiration}")
    private long expiration;

    private SecretKey getKey() {
        return Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
    }

    public String generate(Long userId, String userType) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("userType", userType);
        return Jwts.builder()
            .setClaims(claims)
            .setSubject(String.valueOf(userId))
            .setIssuedAt(new Date())
            .setExpiration(new Date(System.currentTimeMillis() + expiration * 1000))
            .signWith(getKey(), SignatureAlgorithm.HS256)
            .compact();
    }

    public Claims parse(String token) {
        return Jwts.parserBuilder()
            .setSigningKey(getKey())
            .build()
            .parseClaimsJws(token)
            .getBody();
    }

    public boolean isExpired(String token) {
        try {
            return parse(token).getExpiration().before(new Date());
        } catch (Exception e) {
            return true;
        }
    }
}
```

### 6.2 JwtAuthInterceptor

```java
package com.project.groupbuy.security;

import com.project.groupbuy.common.context.SecurityContext;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@Slf4j
@Component
@RequiredArgsConstructor
public class JwtAuthInterceptor implements HandlerInterceptor {

    private final JwtUtil jwtUtil;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
        String authHeader = request.getHeader("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            response.setStatus(401);
            response.setContentType("application/json;charset=UTF-8");
            response.getWriter().write("{\"code\":1002,\"message\":\"未登录\",\"data\":null}");
            return false;
        }
        String token = authHeader.substring(7);
        try {
            var claims = jwtUtil.parse(token);
            Long userId = claims.get("userId", Long.class);
            String userType = claims.get("userType", String.class);
            SecurityContext.set(userId, userType);
            return true;
        } catch (Exception e) {
            response.setStatus(401);
            response.setContentType("application/json;charset=UTF-8");
            response.getWriter().write("{\"code\":1002,\"message\":\"token 无效或过期\",\"data\":null}");
            return false;
        }
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) {
        SecurityContext.clear();
    }
}
```

## 九、Flyway 迁移规范

### 9.1 目录结构

```
src/main/resources/db/migration/
├── V1__init_schema.sql           ← 30 张表 DDL（已生成）
├── V2__init_rbac_data.sql        ← 角色权限种子（已生成）
├── V3__init_business_data.sql    ← 业务种子（已生成）
├── V4__add_xxx.sql               ← 以后改表结构加 V4+，永不改 V1~V3
└── R__views.sql                   ← 可选，重复执行（视图/函数）
```

### 9.2 命名规范

```
V{版本号}__{描述}.sql

版本号规则：
- V1~V3 是已生成的基础脚本，永不修改
- V4+ 每次改表结构加新文件
- 版本号递增，不允许跳号或回退

示例：
V4__add_product_tags_to_product_attribute.sql
V5__add_stock_warn_index.sql
```

### 9.3 Flyway 约束

| 约束 | 来源 |
|---|---|
| 已执行脚本禁止修改 | 约束文档 25 |
| 改表结构必须加 V4+ | 约束文档 25 |
| 新字段必须有默认值，兼容旧数据 | 约束文档 25 |
| 删除字段先废弃（标记 deprecated）再删 | 约束文档 25 |
| Flyway 启动时自动执行 | application.yml flyway.enabled=true |

## 十、Redis 使用规范

### 10.1 Redis 只做缓存/预占，不做唯一数据源（约束文档 21）

```
✅ 正确用途：
   1. 库存预占加速：库存预占写入 Redis 缓存，最终以 MySQL 条件更新为准
   2. 权限缓存：用户权限列表缓存 30min
   3. 分布式锁：幂等回调防重（Redisson 可选）
   4. 限流：接口限流

❌ 禁止用途：
   1. Redis 存唯一库存（MySQL 才是库存真相源）
   2. Redis 存唯一订单（订单必须落 MySQL）
   3. Redis 存唯一支付流水
```

### 10.2 Redis Key 命名规范

```
格式：业务:对象:{id}:用途

示例：
perm:user:123        → 用户 123 的权限列表
stock:lock:sku:456    → SKU 456 的库存预占缓存
token:blacklist:xxx   → JWT 黑名单
order:lock:789        → 订单 789 的分布式锁
```

```java
package com.project.groupbuy.common.util;

public class DesensitizeUtil {

    /** 手机号 138****1001 */
    public static String phone(String phone) {
        if (phone == null || phone.length() < 11) return phone;
        return phone.substring(0, 3) + "****" + phone.substring(7);
    }

    /** 身份证 3101********1234 */
    public static String idCard(String id) {

    }
```
