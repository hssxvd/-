# 社区团购电商系统 前端模块与功能清单

> 版本：v1.0  
> 配套文档：《约束文档》第 15/23/24 章、《项目规划与开发思路》Phase 9、《项目配置与依赖》第七~八章  
> 核心原则：**每个功能点必须能追溯到约束文档具体条款，课题核心功能（分类检索、个性化展示、供应协同、需求预测）必须有对应前端实现**

---

## 一、三端总览

| 端 | 用户 | 风格 | 主色 | 核心任务 | 约束来源 |
|---|---|---|---|---|---|
| 消费者端 | 居民/消费者 | 移动端优先，暖色卡片化 | `#FF6B35` 暖橙 | 浏览→加购→下单→支付→自提→评价 | 约束 23.1 / 24.1 |
| 商家端 | 服务提供人员/商家 | PC 后台，蓝色中性 | `#1677FF` 科技蓝 | 商品/库存/订单/供应/经营分析 | 约束 23.1 / 24.2 |
| 管理端 | 社区/平台管理员 | PC 后台，深色侧边栏 | `#1677FF` 科技蓝 | 用户/角色/权限/审核/全局统计/预测 | 约束 23.1 / 24.3 |

### 课题核心功能三端分布

| 课题核心功能 | 消费者端 | 商家端 | 管理端 |
|---|---|---|---|
| 供应与库存协同 | 查看库存预警提示 | **供应计划 CRUD + forecast_qty 关联 + 人工调整** | 全局供应监控 |
| 分类检索与个性化展示 | **分类筛选 + 特色属性筛选 + 个性化推荐（可关闭）** | 基础排序（无个性化） | 基础排序 |
| 购物车和订单管理 | **完整闭环** | 订单处理 + 履约分配 | 全局订单监控 |
| 模拟支付与履约跟踪 | **模拟支付 + 自提扫码** | 履约分配/完成 | 全局履约监控 |
| 售后评价与经营分析 | **售后申请 + 评价** | 售后审核 + 评价回复 + 经营分析图表 | 全局统计 |
| 需求预测（智能化） | 不可见 | **关联供应计划 + MAE vs 基线对比展示** | **触发预测 + 评估报告** |
